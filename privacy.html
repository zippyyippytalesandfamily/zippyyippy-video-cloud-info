Privacy notice

Your production files stay private.

Effective November 22, 2026. This notice describes the owner-operated ZippyYippy Video Cloud app and this public information site.

Information the app uses

The app accesses the Google account email to confirm the intended owner, and file content and metadata needed for video production: reference images, story and production rules, benchmark videos, review outputs, file identifiers, sizes and integrity hashes. It requests Google Drive's drive.file scope for files created by the app or explicitly selected or shared with it. It does not request unrestricted Drive access.

Purpose and processing

Files are used to prepare, render, verify and review ZippyYippy videos. Selected files may be downloaded to temporary GitHub-hosted runners for processing. Private outputs are stored in Google Drive. Generation-provider processing requires an owner-approved production request; connecting Google Drive alone does not authorize paid generation or public posting.

Sharing and service providers

Google Drive stores files and GitHub hosts code, encrypted authorization secrets and cloud jobs. A selected generation provider may receive the specific inputs needed for an approved job. This public site contains no links to private production files. Google user data is not sold, used for advertising, or used by this app to train generalized AI models.

Authorization and safeguards

OAuth credentials used by cloud jobs are stored in encrypted GitHub environment secrets, not in public source code or review links. Drive copies are created privately. Access is limited to authorized accounts and services; account security and provider policies also apply.

Retention and deletion

Production and reference files remain in the owner's Drive until the owner deletes them. Cloud verification artifacts are currently configured to expire after 14 days. Cloud job logs, repository history and provider records follow the relevant service's retention settings. Temporary hosted-runner workspaces are used only for the job. Deleting a Drive file does not automatically remove separate copies or service records.

Your choices

The owner can revoke Google access at Google Account connections, delete Drive copies and remove GitHub secrets or artifacts. Revocation stops future authorized access but does not itself delete existing files. Contact zippyyippytales@gmail.com to request help with access or deletion.

This public website

This static site has no login, upload form, advertising or analytics code. The hosting provider may process ordinary request information, such as IP addresses, under its own policies. The app is operated by the account owner and does not invite children to create accounts or submit personal information.

Changes and contact
